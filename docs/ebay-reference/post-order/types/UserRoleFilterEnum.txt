# UserRoleFilterEnum

This enumeration type identifies the different types of user role values that can be used with the role query parameter.

Calls that use one or more values of UserRoleFilterEnum:

/post-order/v2/cancellation/search GET,
/post-order/v2/return/search GET

## Enumeration Values

Value |
Description |

BUYER |
This value is used if you only wanted to search for cancel or return actions initiated by the buyer. |

SELLER |
This value is used if you only wanted to search for cancel or return actions initiated by the seller. |

* See the Enumeration Index to see exact use of each enumeration value in the API.
